# Living Room VR

<p align="center">
  <img src="docs/screens/LR094.jpg" width="100%" alt="Art Deco living room rendered in Blender Cycles">
</p>

**A cross-platform chores game set in 120 photoreal living rooms**, generated in Blender, textured with full PBR materials and lit with Cycles-baked lighting.
Walk through each house and get it guest-ready: put the pillows back, reshelve the books, straighten the art, vacuum, water the plants and take out the trash.

<p align="center">
  <a href="https://jaineil32624.github.io/living-room-vr/"><b>▶ Play in your browser / Meta Quest</b></a>
</p>

## Controls

| Device | Move | Look / turn | Grab · use | Drop · throw | Chores |
|---|---|---|---|---|---|
| VR controllers | left stick | right stick (snap), push forward to teleport | grip (works at a distance) / trigger | release grip | X/Y or A/B (wrist panel) |
| VR hand tracking | — | — | pinch | release pinch | — |
| Keyboard + mouse | WASD | mouse (or drag) | E / click | Q / right-click | Tab · 1–6 jump to a room · H front door |
| Gamepad | left stick | right stick | A / ✕ | B / ○ | Y / △ |
| Phone / tablet | left joystick | drag right side | USE | DROP | TASKS |
| TV remote | ↑ ↓ | ← → | OK | Back | — |

URL shortcuts: `?house=7` starts house 7, `?room=LR045` loads one room.

## What's in this repo

| Path | Contents |
|---|---|
| `index.html` | The whole game (Three.js r170 + WebXR), no build step |
| `rooms/` | 120 game-ready rooms (`.glb`, Draco-compressed) + baked lightmaps |
| `thumbs/` | Room previews |
| `rooms.json` | Room index: style, size, door, windows, lightmap scale |
| `lib/` | Three.js, Draco decoder, three-mesh-bvh (bundled, works offline) |
| `docs/screens/` | Images used in this README |
| `Play on this PC.bat` | Runs a local server with Blender's Python and opens the game |
| `ports/unity/` | Unity 6 source (glTFast loader, lightmap shaders, chores, HUD). Rooms ship in the Unity download |
| `ports/godot/` | Godot 4 source (GDScript + shaders). Rooms ship in the Godot download |
| `ports/android/` | Android app that wraps the web game offline (`build_apk.bat` rebuilds the APK) |

## Run it yourself

- **Online:** just open the Pages link above.
- **On Windows:** download the ZIP, unzip, double-click `Play on this PC.bat`.
- **Anywhere else:** serve the folder with any static server (for example `python -m http.server 8080`) and open `http://localhost:8080`. Browsers block the game from `file://`.
- **On a Quest:** it must be served over **https** (GitHub Pages does this), then press **Enter VR**.

## Regenerating the rooms

The Blender generator (`lrgen.py`) and batch scripts live in `Documents/LivingRoomVR/tools` on the build machine:

```
python bake_all.py   # one headless Blender per room: build → Cycles render → bake lightmap → export
```

About 25–30 s per room on an RTX 5080.

## Console stores

Native PlayStation / Xbox / Nintendo releases need an approved developer account with each platform (PlayStation Partners, ID@Xbox, Nintendo Developer Portal) plus their dev kits and certification. The Unity and Godot projects above are the starting point for that — both engines export to Xbox, PlayStation and Switch once you have the platform's developer access.
